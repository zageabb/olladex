# Olladex Documentation

The maintained Olladex knowledge base starts at:

**[docs/README.md](docs/README.md)**

Use it as the documentation entry point for:

- the complete v0.8.1 user/operator manual;
- installation, environment and deployment configuration;
- repeatable development, Git/GitHub and multi-agent workflows;
- module and extension inventory;
- Office expansion branch documentation;
- architecture and developer reference;
- troubleshooting;
- editable Mermaid/Graphviz workflow sources and rendered SVG illustrations.

The documentation distinguishes released `main` capability from optional dependencies, expansion-branch features and planned work. When behaviour changes, update the relevant documentation in the same pull request as the code change.
